# পণ্য আর দোকান যোগের নিয়ম

দাম কীভাবে আপডেট হয়, নতুন পণ্য কীভাবে যোগ করবেন, আর ফ্রি সীমার মধ্যে কতটা রাখা যায়। মালিক আর AI এজেন্ট দুজনের জন্য।

## কীভাবে চলে

- **`prices`, প্রতি ৬ ঘণ্টায়:** ডেটাবেসের প্রতিটা দোকান-লিংক একবার পড়ে, ওই পাতার সব ভার্সনের দাম একসাথে আপডেট করে। ১০টা দোকানের সবগুলো, আর অ্যাডমিনের হাতে বসানো দামও (বিক্রেতার ওয়েবসাইট থাকলে)।
- প্রথমবার প্রতিটা দাম পাতার যে অপশনের সাথে হুবহু মেলে, সেটায় বাঁধা হয় (`offers.variant_key`)। পরের বার থেকে সেই অপশনটাই পড়া হয়, তাই এক লিংকে ৪টা স্টোরেজ থাকলেও কোনোটার দাম অন্যটায় বসে না।
- **`discover`, পণ্য বা ভার্সন যোগ করলেই, আর প্রতি রাতে:** দোকানগুলোর sitemap আর ক্যাটাগরি পাতা থেকে পণ্যটা খুঁজে নতুন দাম বসায়।
- কিছু মেলাতে না পারলে চুপচাপ বাদ যায় না। কাজের বার্তায় পণ্য আর দোকানের নাম আসে (অ্যাডমিন → কাজ, আর লগ), অনিশ্চিতগুলো "যাচাই বাকি" পেজে যায়।

## অ্যাডমিন থেকে নতুন পণ্য

1. **নাম:** ব্র্যান্ড আলাদা ঘরে (`Samsung`), মডেলে দোকানে যেমন লেখা থাকে (`Galaxy A17 5G`)। Pro, Max, Plus, Ultra, FE, 5G বাদ দেবেন না, এগুলো দিয়েই আলাদা মডেল চেনা হয়।
2. **সাইজ আর চিপ** নামে রাখা যায়: `MacBook Air 13" M5`, `iPad Air 11-inch (M4)`। দোকানের লিংকে এগুলো না থাকলেও মেলে, কিন্তু অমিল থাকলে বাদ যায় (13" এর পাতা 15" এ বসে না)।
3. **ভার্সন**, প্রতি লাইনে `লেবেল | অফিসিয়াল দাম`:

   | পণ্য | লেবেল |
   |---|---|
   | ফোন | `8GB / 256GB`; সব ভার্সনে RAM এক হলে শুধু `256GB` |
   | ট্যাবলেট | `128GB Wi-Fi`, `128GB Wi-Fi + Cellular` |
   | ঘড়ি | `42mm GPS`, `46mm GPS + Cellular` |
   | Mac | `M5 16GB / 512GB`; একই RAM আর স্টোরেজে GPU কোর আলাদা হলে `M5 10-core GPU 16GB / 1TB` |
   | এক ভার্সনের পণ্য (ইয়ারবাড, হেডফোন) | `Standard` |

   রং দিয়ে ভার্সন বানাবেন না। দোকানে রং, region, সিম বা ওয়ারেন্টি আলাদা অপশন হলে তার মধ্যে স্টকে থাকা সবচেয়ে কম দামটা নেওয়া হয়, আর region টা দামের পাশে দেখায়।
4. **অফিসিয়াল দাম দিন।** কভার বা গ্লাসের মতো ভুল লিস্টিং এটা দিয়েই বাদ পড়ে: অফিসিয়ালের ৪০% এর কম বা আড়াই গুণের বেশি দাম নেওয়া হয় না।
5. **সেভ করলেই `discover` চালু হয়।** GitHub token সেট থাকলে ১-২ মিনিটে শুরু হয়, ৫-১০ মিনিটে শেষ। token না থাকলে রাতের run এ।
6. **পরে দেখুন:** অ্যাডমিন → কাজ → "নতুন পণ্য খোঁজা আর মেলানো" এর বার্তা (কয়টা দাম এল, কয়টা যাচাইয়ে)। যাচাই বাকি পেজে অনিশ্চিতগুলো অনুমোদন দিন। যেসব দোকানের এক পাতায় সব স্টোরেজ থাকে না আর শিরোনামেও লেখা থাকে না, সেগুলো এখানে আসে।
7. **কোনো দোকানে পাওয়া না গেলে** বার্তায় "কোনো দোকানে পাওয়া যায়নি" সহ নাম আসে। তখন নাম দোকানের মতো করে বদলান, অথবা দোকানের পাতার লিংক দিয়ে হাতে দাম যোগ করুন; `prices` সেটাও নিয়মিত আপডেট করবে।

পরে ভার্সন যোগ করলেও `discover` আবার চলে, আগে থেকে জানা পাতাতেও নতুন ভার্সনটা খোঁজে।

## একসাথে অনেক পণ্য (`data/catalog`)

1. `data/catalog/<ক্যাটাগরি>.json` এ আগের এন্ট্রির মতো পণ্য, ভার্সন, আর দোকানের লিংক ও দাম লিখুন।
2. `npm run worker:check` চালান। শেষ লাইনে "০টা সিঙ্ক হবে না" না এলে ✗ চিহ্নের লাইনগুলো ঠিক করুন: লিংক ভুল, বা লেবেল দোকানের অপশনের সাথে মেলে না। একটা পণ্য বা দোকান দেখতে: `npm run worker:check -- "iPhone 17"` বা `npm run worker:check -- dazzle`।
3. `npm run catalog:specs`, `npm run catalog:build`, তারপর Supabase এ `supabase/seed.sql` চালান। আগের সারি বদলায় না, শুধু নতুনগুলো যোগ হয়, আর `discover` নিজে চালু হয়।
4. `npm run worker:check -- --new` দেখায়, দাম না জেনে নতুন পণ্য হিসেবে `discover` কতটা নিজে খুঁজে পেত।

## নতুন দোকান

1. Terms of Use আর robots.txt দেখুন। 403, bot challenge বা robots এ বন্ধ থাকলে দোকান বাদ; নিয়ম [ডেটার উৎস](features/17-data-sources.md) এ।
2. `workers/stores/index.ts` এ একটা `sitemapStore({...})` এন্ট্রি: product sitemap, পণ্যের পাতার path, দোকানটা মূলত অফিসিয়াল না আনঅফিসিয়াল।
3. পাতায় ভার্সনের দাম কোথায় আছে দেখে `variants` parser দিন। WooCommerce হলে `wooVariants`; অন্য ধরনের জন্য `workers/stores/parsers.ts` এ নতুন। শুধু একটা দাম থাকলে parser লাগে না, JSON-LD থেকে আসে।
4. Supabase এর `sellers` এ দোকানটা যোগ করুন, ওয়েবসাইট একই ডোমেইনে।
5. `npm run worker:dry` আর `npm run worker:check -- <ডোমেইন>` দিয়ে যাচাই, তারপর push।
6. এখনই খোঁজাতে: অ্যাডমিন → কাজ → `discover` → "এখনই চালান" (বা GitHub → Actions → discover → Run workflow)। যে দোকানের এখনো একটাও দাম নেই, হাতে চালালেও সেখানে পুরো ক্যাটালগ খোঁজা হয় (অন্য দোকানে হাতে চালালে শুধু নতুন পণ্য)। কয়েক মিনিট পর অ্যাডমিন → যাচাই তালিকায় অনিশ্চিত ম্যাচগুলো আসবে।

এর পরে আলাদা কিছু লাগে না: ওই দোকানের লিংকওয়ালা সব দাম পরের `prices` run থেকে সিঙ্ক হয়, আর `discover` রাতে সেখানে ক্যাটালগের সব পণ্য খোঁজে।

## নতুন ক্যাটাগরি

অ্যাডমিন → ক্যাটাগরি থেকে যোগ করলেই চলে; সিঙ্ক আর খোঁজা ক্যাটাগরি দেখে না, পণ্যের নাম আর ভার্সন দেখে। তিনটা জিনিস হাতে মেলাতে হয়:

1. Star Tech এর product sitemap নেই, worker ওদের ক্যাটাগরি পাতা ঘোরে। নতুন ধরনের পণ্য হলে (যেমন Windows ল্যাপটপ, টিভি) `workers/stores/index.ts` এর `STARTECH_CATEGORIES` এ ওদের ক্যাটাগরির path যোগ করুন (`https://www.startech.com.bd/sitemap.xml` এ পাবেন)।
2. ভার্সনের লেবেলে সেই ধরনের পণ্যে যা দিয়ে দাম আলাদা হয় তা-ই লিখুন: স্টোরেজ/RAM (`16GB / 512GB`), ইঞ্চি (`55"`), mm, Wi-Fi/Cellular, চিপ। শুধু রং বা ওয়ারেন্টি দিয়ে আলাদা হলে এক ভার্সন।
3. অ্যাডমিন → সেটিংস → SEO শিরোনাম আর বর্ণনা (বাংলা + English) ইচ্ছে করেই সাধারণ রাখা (শিরোনামে কোনো ক্যাটাগরির নাম নেই, বর্ণনায় "মোবাইল, ল্যাপটপ, গ্যাজেট … আরও"), যাতে নতুন ধরনের পণ্য (যেমন স্কিনকেয়ার) এলে ভুল না হয়। বড় কোনো ক্যাটাগরি এলে বর্ণনায় নামটা জুড়ে দিন; ৭০/১৬০ অক্ষরের মধ্যে রাখুন।

## ফ্রি সীমা

| জিনিস | ফ্রি সীমা | এখন (৫৩ পণ্য, ৫৪৫ দাম, ৩৬৯ লিংক) |
|---|---|---|
| GitHub Actions | private repo এ মাসে ২,০০০ মিনিট, public এ সীমা নেই | `prices` প্রতি run এ ২-৩ মিনিট, দিনে ৪ বার; সব job মিলিয়ে মাসে প্রায় ৬৫০ মিনিট |
| Supabase | ৫০০ MB, মাসে ৫ GB egress; ৭ দিন অব্যবহৃত থাকলে pause | কয়েক MB; worker প্রতি ৬ ঘণ্টায় চলে বলে pause হয় না। সাইট build এ বেক করা JSON পড়ে বলে ভিজিটরের egress লাগে না; পণ্য যত বাড়ুক না কেন |
| AI (নিজের OpenAI-compatible সার্ভিস) | সাবস্ক্রিপশনের সীমা | শুধু অস্পষ্ট পাতায়, রাতে কয়েকটা অনুরোধ; সস্তা ছোট মডেলই যথেষ্ট |

- `prices` এর সময় বাড়ে সবচেয়ে বেশি লিংকওয়ালা দোকানের সাথে, প্রতি লিংকে প্রায় ১ সেকেন্ড (প্রতি দোকানে একসাথে ২টার বেশি অনুরোধ যায় না)।
- private repo তে প্রতি ৬ ঘণ্টায় চালালে মোট ৩০০টার মতো পণ্য রাখা যায়, মানে প্রতি ক্যাটাগরিতে ৪০-৫০টা চলতি মডেল। এর বেশি হলে repo public করুন, অথবা `.github/workflows/prices.yml` এর cron প্রতি ১২ ঘণ্টায় করুন (`17 */12 * * *`)।
- বাজার থেকে উঠে যাওয়া মডেল মুছে দিন; পণ্য মুছলে তার দামও মুছে যায়।
