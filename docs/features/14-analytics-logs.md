# ১৪ ভিজিটর গোনা আর লগ

**অবস্থা:** 🟡 আংশিক (কোড শেষ, আসল ডেটা নেই)

## যা আছে

- প্রতিটা পেজ খোলায় `page_views` এ এক সারি (`src/services/analytics.ts`)। ২৫ অক্টোবরের আগে insert কখনো পাঠানো হতো না (query `await` করা ছিল না), তাই পুরনো গোনা শূন্য। ভিজিটর চেনা হয় ব্রাউজারের একটা এলোমেলো id দিয়ে, নাম বা IP রাখা হয় না। `/admin` গোনা হয় না।
- অ্যাডমিন → ভিজিটর: দিনভিত্তিক ভিজিটর আর ভিউ, বেশি দেখা পেজ (`visitor_stats`, `top_pages` ফাংশন)।
- ঐচ্ছিক Cloudflare Web Analytics: সেটিংসে token দিলে সাইটে তাদের script বসে।
- লগ: `job_runs` (worker) আর `audit_log` (অ্যাডমিনের প্রতিটা কাজ), অ্যাডমিন → লগ পেজে।

- **ভিজিটরের বিস্তারিত (২৫ অক্টোবর):** প্রতিটা ভিজিটে দেশ (Cloudflare এর `cf-ipcountry`) আর ডিভাইস (মোবাইল/ট্যাবলেট/কম্পিউটার, ব্রাউজারের ধরন থেকে) রাখা হয়, IP বা পুরো user-agent না। খোঁজা শেষ হলে একবার `/search/?q=…` হিসেবে গোনা হয় (প্রতি অক্ষরে নয়)। অ্যাডমিন → ভিজিটর: আলাদা ভিজিটর, ফিরে আসা ভিজিটর, কোন দেশ, কোন ডিভাইস, কোথা থেকে এসেছে, সবচেয়ে বেশি দেখা পণ্য, কী লিখে খোঁজা (`visitor_insights()`, শুধু পেজ খুললে হিসাব, সর্বোচ্চ ৯০ দিন)। সব আগের সীমার ভেতরে: দিনে সর্বোচ্চ ১০,০০০ সারি, ৯০ দিন পরে মোছে।
