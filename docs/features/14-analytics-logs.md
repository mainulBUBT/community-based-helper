# ১৪ ভিজিটর গোনা আর লগ

**অবস্থা:** 🟡 আংশিক (কোড শেষ, আসল ডেটা নেই)

## যা আছে

- প্রতিটা পেজ খোলায় `page_views` এ এক সারি (`src/services/analytics.ts`)। ভিজিটর চেনা হয় ব্রাউজারের একটা এলোমেলো id দিয়ে, নাম বা IP রাখা হয় না। `/admin` গোনা হয় না।
- অ্যাডমিন → ভিজিটর: দিনভিত্তিক ভিজিটর আর ভিউ, বেশি দেখা পেজ (`visitor_stats`, `top_pages` ফাংশন)।
- ঐচ্ছিক Cloudflare Web Analytics: সেটিংসে token দিলে সাইটে তাদের script বসে।
- লগ: `job_runs` (worker) আর `audit_log` (অ্যাডমিনের প্রতিটা কাজ), অ্যাডমিন → লগ পেজে।

## যা বাকি

- [ ] ভিজিটর বেশি হলে `page_views` বড় হবে। পুরনো সারি মাসিক হিসাবে গুটিয়ে রাখা বা মুছে ফেলা।
- [ ] কোন পণ্য বেশি দেখা হচ্ছে তা `products.popularity` তে বসানো (worker দিয়ে)।
- [ ] কোন দোকানের লিংকে কতজন গেছে গোনা (affiliate আলোচনার জন্য দরকার)।
