# ০৯ অ্যাডমিন প্যানেল

**অবস্থা:** ✅ শেষ (ডেমো মোডে পরীক্ষিত, আসল ডেটাবেসে নয়)

একই Next.js অ্যাপে `/admin/` এ। সব পেজ client-side, লেখার অনুমতি Supabase RLS দেয় (`is_admin()`)।

## পেজ

| পেজ | রুট | কী করা যায় |
|---|---|---|
| ড্যাশবোর্ড | `/admin/` | আজকের ভিজিটর, যাচাই বাকি, সমস্যায় থাকা কাজ, ১৪ দিনের চার্ট |
| যাচাই বাকি | `/admin/review/` | AI এর মেলানো, সন্দেহজনক দাম (৬০% এর বেশি বদল), ক্রেতার পাঠানো দাম: অনুমোদন বা বাদ |
| বিক্রেতা | `/admin/sellers/` | যোগ, সম্পাদনা, মোছা, যাচাই চালু/বন্ধ, সক্রিয়/বন্ধ |
| পণ্য ও দাম | `/admin/products/` | নতুন পণ্য (ভার্সনসহ), হাতে দাম বসানো, তালিকা |
| পণ্য সম্পাদনা | `/admin/products/edit/?id=` | তথ্য, জনপ্রিয়তা, ভার্সন যোগ/মোছা, প্রতিটা দামের দাম, স্টক, সাইটে দেখানো, মোছা, পুরো পণ্য মোছা |
| অফার | `/admin/offers/` | কার্ড, bKash, কিস্তি অফার যোগ, সম্পাদনা, চালু/বন্ধ, মোছা |
| কাজ ও AI | `/admin/jobs/` | প্রতিটা cron চালু/বন্ধ, "এখনই চালান", LLM সেটিংস আর সংযোগ পরীক্ষা, Telegram সতর্কবার্তা |
| ভিজিটর | `/admin/visitors/` | ৭, ৩০, ৯০ দিনের ভিজিটর আর পেজ ভিউ, বেশি দেখা পেজ |
| লগ | `/admin/logs/` | কাজের লগ (`job_runs`) আর অ্যাডমিনের কাজ (`audit_log`) |
| সেটিংস | `/admin/settings/` | সাইটের নাম, পরিচয়, যোগাযোগ, লোগো, হোম পেজের শিরোনাম (বাংলা/English), দ্রুত খোঁজা, উপরের নোটিশ, SEO, Cloudflare Analytics token |

## ফাইল

`src/app/admin/*`, `src/components/admin/*`, `src/services/admin/*`। প্রতিটা অ্যাডমিন কাজ `audit_log` এ লেখা হয় (`services/admin/audit.ts`)।

## ডেমো মোড

Supabase না থাকলে সব বদল ব্রাউজারের মেমোরিতে থাকে, পেজ রিলোড দিলে মুছে যায়। লগইনের তথ্য `.env.example` এ।
