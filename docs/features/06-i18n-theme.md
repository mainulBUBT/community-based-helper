# ০৬ বাংলা/English আর লাইট/ডার্ক

**অবস্থা:** 🟡 আংশিক (ইউজারের সাইট শেষ, অ্যাডমিন শুধু বাংলা)

## যা আছে

- ডিফল্ট বাংলা। হেডারের বোতামে English। পছন্দ localStorage এ থাকে (`src/lib/preferences.ts`)।
- সব লেখা `src/i18n/bn.ts` আর `src/i18n/en.ts` এ। `en.ts` এর ধরন `bn.ts` থেকে আসে, তাই কোনো চাবি বাদ পড়লে typecheck আটকায়।
- `useI18n()` (`src/hooks/useI18n.ts`) দেয় `t` (লেখা), `num` (বাংলায় সংখ্যা বাংলা অঙ্কে), `ago` ("২ ঘণ্টা আগে")।
- দাম সবসময় ইংরেজি অঙ্কে (`৳39,999`), গোনা সংখ্যা বাংলায় (`৪টা দোকানে`)।
- ডিফল্ট লাইট মোড। বোতামে ডার্ক মোড, পছন্দ মনে রাখে। পেজ খোলার আগেই `<head>` এর ছোট script থিম বসায়, তাই ঝলক দেখা যায় না।

## যা বাকি

- [ ] অ্যাডমিন প্যানেল English এ (এখন শুধু বাংলা)।
- [ ] English এর জন্য আলাদা SEO পেজ (`/en/...`)। এখন static HTML বাংলায়, English শুধু ব্রাউজারে বদলায়।
- [ ] সাইটের নামের English রূপ সেটিংসে।
