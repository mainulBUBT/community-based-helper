# ০৫ ক্রেতার পাঠানো দাম

**অবস্থা:** 🟡 আংশিক

## যা আছে

- "দাম জানান" ডায়ালগ (`src/components/forms/SubmitPriceDialog.tsx`), হোম, খোঁজা, পণ্যের পেজ আর ফুটার থেকে খোলে। ঘর: পণ্য, দাম, দোকান/গ্রুপের নাম, ফোন, লিংক।
- পাঠানো দাম যায় Edge Function `submit-price` দিয়ে: Turnstile যাচাই, ঘরগুলো ছাঁকা (দাম, ফোন, লিংক, দৈর্ঘ্য), তারপর `review_queue` এ `kind = 'submission'`। এক IP থেকে ১০ মিনিটে ৫টা, সবাই মিলে ৬০টা। ব্রাউজার সরাসরি টেবিলে লিখতে পারে না। ফর্মেও একই যাচাই আর Turnstile বক্স।
- অ্যাডমিন → যাচাই বাকি পেজে "সাইটে দিন" বা "বাদ দিন"।
- worker এর `services/apply-approved.ts` অনুমোদিত `match` আর `anomaly` কে আসল offer এ বসায়। ক্রেতার পাঠানো দামে পণ্য আর দোকান লেখা থাকে সাধারণ লেখায়, কোনো id থাকে না। তাই এগুলো নিজে থেকে বসে না, অ্যাডমিনকে "পণ্য ও দাম → হাতে দাম বসান" দিয়ে বসাতে হয়।
