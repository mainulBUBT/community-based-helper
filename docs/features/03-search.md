# ০৩ খোঁজা আর ফিল্টার

**অবস্থা:** ✅ শেষ

## যা আছে

- **সার্চবক্স** (`src/components/search/SearchBox.tsx`): টাইপ করার সাথে সাথে ৬টা পণ্যের পরামর্শ দামসহ। খালি থাকলে আগের খোঁজা দেখায়। কিবোর্ডের তীর দিয়ে চলে (combobox)। উপরের হেডারে সব পেজে, খোঁজার পেজে আলাদা।
- **বাংলা বানান:** আইফোন, স্যামসাং, শাওমি, রেডমি, ম্যাকবুক, ঘড়ি ইত্যাদি লিখলেও খুঁজে পায় (`src/utils/catalog.ts` এর `ALIASES`)। "মোবাইল", "দাম" এর মতো শব্দ বাদ দেয়।
- **আগের খোঁজা:** localStorage এ শেষ ৬টা (`src/lib/recent-searches.ts`)।
- **ফিল্টার** (`src/app/(site)/search/SearchView.tsx`): ক্যাটাগরি, ব্র্যান্ড, দামের সীমা, স্টকে আছে, আনঅফিসিয়ালও দেখানো। সাজানো: জনপ্রিয়, কম দাম আগে, বেশি দাম আগে, বেশি কমেছে। সব ফিল্টার URL এ থাকে, তাই লিংক শেয়ার করা যায়।
- খোঁজার ফল পণ্য কার্ডের গ্রিডে।

## যা বাকি

- [ ] পণ্য অনেক হলে ব্রাউজারে সব না এনে Supabase এ full-text search।
- [ ] ALIASES এ আরো ব্র্যান্ড আর মডেলের বাংলা বানান যোগ।
