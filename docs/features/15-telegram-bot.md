# ১৫ দোকানের জন্য Telegram bot

**অবস্থা:** ⬜ শুরু হয়নি (শুধু সতর্কবার্তা পাঠানো আছে)

## লক্ষ্য

যে দোকান শুধু ফেসবুকে দাম দেয় (যেমন বসুন্ধরা সিটি বা মোতালিব প্লাজার ছোট দোকান), তারা Telegram bot এ পোস্টের লেখা বা স্ক্রিনশট পাঠাবে। AI মডেল, ভার্সন, অফিসিয়াল/আনঅফিসিয়াল আর দাম বের করবে, তারপর `review_queue` এ `submission` হিসেবে যাবে। অ্যাডমিন অনুমোদন দিলে সাইটে "দোকান নিজে জানিয়েছে" লেখাসহ ৭ দিন দেখাবে।

## যা আছে

- `workers/lib/telegram.ts`: job ব্যর্থ হলে অ্যাডমিনকে বার্তা পাঠায়।
- token আর chat id অ্যাডমিন → কাজ ও AI থেকে বসে।

## যা বানাতে হবে

- [ ] bot এ বার্তা আসার পথ: Supabase Edge Function webhook (ফ্রি)।
- [ ] কোন Telegram অ্যাকাউন্ট কোন বিক্রেতা, তা জোড়া লাগানো (`sellers` এ `telegram_chat_id` ঘর, নতুন migration)।
- [ ] ছবি Supabase Storage এ রাখা, AI দিয়ে পড়া।
- [ ] বিক্রেতাকে উত্তর: "পেয়েছি, যাচাইয়ের পর সাইটে আসবে"।
