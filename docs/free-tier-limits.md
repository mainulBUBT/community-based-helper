# ফ্রি সার্ভিসের সীমা আর কবে শেষ হতে পারে

হিসাব ২৫ অক্টোবর ২০২৬ এর কোড, লোকাল build আর GitHub এর শেষ ৮৫টা run থেকে। সীমাগুলো সার্ভিসের নিজের পাতা থেকে; বদলাতে পারে, বছরে একবার মিলিয়ে নিন।

| সার্ভিস | ফ্রি সীমা | আমাদের এখন | কখন শেষ হতে পারে |
|---|---|---|---|
| Cloudflare Pages ফাইল | প্রতি deploy এ ২০,০০০ ফাইল | প্রতি পণ্য, বিক্রেতা বা ক্যাটাগরিতে ১২টা ফাইল (দুই ভাষা × ৬), সাথে ~২৬০টা সাধারণ; ১৮২ পণ্যে ~৩,১০০ | পণ্য + বিক্রেতা + ক্যাটাগরি মিলে ~১,৬৪০ পার হলে deploy ব্যর্থ হবে |
| Cloudflare Pages build | মাসে ৫০০ | দিনে ৪টা নির্ধারিত rebuild + প্রতি push, মাসে ~১৫০ | নিরাপদ |
| Supabase ডেটাবেস | ৫০০ MB | `page_views` সবচেয়ে বেশি: দিনে সর্বোচ্চ ১০,০০০, ৯০ দিন পরে মোছে, সবচেয়ে খারাপ অবস্থায় ~১৭০ MB; বাকি সব মিলে কয়েক MB | এখনকার সীমায় নিরাপদ |
| Supabase egress | মাসে ৫ GB | ভিজিটর Supabase থেকে পড়ে না (বেক করা JSON CDN থেকে); rebuild আর worker মিলে আনুমানিক মাসে ১ GB এর কম | নিরাপদ |
| Supabase Edge Function | মাসে ৫ লাখ কল | শুধু দাম জানানো | কেউ সরাসরি function এর ঠিকানায় লাগাতার অনুরোধ পাঠালে প্রতিটা কল গোনা হয় (Turnstile এ বাদ পড়লেও); ঘণ্টায় ~৩.৬ লাখ অনুরোধের আক্রমণে মাসের কোটা শেষ |
| Supabase ঘুমিয়ে পড়া | ৭ দিন কোনো কাজ না হলে প্রজেক্ট pause | worker প্রতি ৬ ঘণ্টায় ডাকে | GitHub এর cron বন্ধ হলে (নিচে) ৭ দিন পরে |
| GitHub Actions | public repo, মিনিট সীমাহীন; একসাথে ২০টা job, cache ১০ GB | মাসে ~৭০০ মিনিট, আর `discover` এখন প্রতি দোকানে আলাদা job (প্রতি run এ দোকান × ~১.৫ মিনিট); দোকানের জমা তালিকা cache এ কয়েক MB করে | নিরাপদ; ২০ এর বেশি দোকান হলে বাকিরা লাইনে অপেক্ষা করে, পুরনো cache GitHub নিজে মোছে |
| GitHub নির্ধারিত workflow | public repo তে ৬০ দিন কোনো কাজ (commit ইত্যাদি) না হলে cron নিজে থেকে বন্ধ | — | **সবচেয়ে বড় ঝুঁকি:** ৬০ দিন commit না হলে দাম আনা আর rebuild থামবে, সাইট পুরনো দাম দেখাবে; তার ৭ দিন পরে Supabase pause, অ্যাডমিন, ভিজিট গোনা আর দাম জানানো বন্ধ |
| নিজের AI সাবস্ক্রিপশন | প্রোভাইডারের কোটা | এক run এ সর্বোচ্চ ২০০ কল (`LLM_CALL_LIMIT`), আর Gemini দিয়ে পাতা পড়া ১২০টা (`AI_READ_LIMIT`); সবচেয়ে খারাপ অবস্থায় দিনে ~১,১০০ কল | সীমা শেষ হলে AI ছাড়া চলে, অনিশ্চিত মিল যাচাইয়ে যায় |
| ডোমেইন `dordam.app` | ফ্রি না, বছরে নবায়ন | — | নবায়ন না করলে সাইট বন্ধ; Cloudflare এ auto-renew চালু রাখুন |
| দোকানের ছবি | দোকানের CDN থেকে সরাসরি দেখানো | — | দোকান ছবি সরালে বা hotlink আটকালে সেই ছবি ভাঙবে |

## কী করবেন

- **৬০ দিনের নিয়ম:** মাসে অন্তত একবার repo তে আসল কাজ (commit) করুন। GitHub নিজে "keepalive" ধরনের কৌশলকে terms ভাঙা ধরে (এরকম জনপ্রিয় টুলের repo তারা বন্ধ করেছে), তাই সেটা করা হয়নি। GitHub ইমেইলে আগে সতর্ক করে, সেটা খেয়াল রাখুন। বন্ধ হলে Actions পাতা থেকে এক ক্লিকে আবার চালু করা যায়।
- **পণ্য ~১,৫০০ ছাড়ানোর আগে:** Cloudflare Workers Paid ($৫/মাস, ১ লাখ ফাইল), অথবা English পণ্য পেজ বাদ দিলে ফাইল অর্ধেক (SEO তে ক্ষতি)।
- **Edge Function এ আক্রমণ:** দেখা দিলে দাম জানানো Cloudflare Pages Function এ সরানো আর Cloudflare এর ফ্রি rate-limit নিয়ম বসানো।
- মাসে একবার Supabase → Usage আর Cloudflare → Pages পাতায় সংখ্যাগুলো দেখে নিন।
