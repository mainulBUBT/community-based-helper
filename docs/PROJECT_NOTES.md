# রাতজাগা (RaatJaga) — প্রকল্প নোট

সূত্র: `raatjaga-proposal.pdf` (সংস্করণ ১.০, ১৭ অক্টোবর ২০২৬)। এই নোট পুরো প্রস্তাবনার সংক্ষিপ্ত সংরক্ষণ — ভবিষ্যতের সেশনে রেফারেন্সের জন্য।

## এক লাইনে
রাতের জরুরি প্রয়োজনীয় জায়গাগুলোর (ফার্মেসি, ফুয়েল, এটিএম, হাসপাতাল, রক্ত ইত্যাদি) কমিউনিটি-ভেরিফায়েড অনলাইন ডিরেক্টরি — মোবাইল-ফার্স্ট ওয়েব, সম্পূর্ণ বাংলায়। মূল প্রতিশ্রুতি: **"এখানে যা দেখছেন, সেটা এখন খোলা।"**

## সমস্যা
- রাত ১০টার পর "কাছে কোন ফার্মেসি এখন খোলা" — বাংলাদেশে নির্ভরযোগ্য উত্তর নেই।
- ঢাকার OSM-এ ১,৮২১টি ফার্মেসি ম্যাপড, মাত্র ১০টিতে "২৪ ঘণ্টা" তথ্য → ৯৯.৫% ক্ষেত্রে রাতের সত্য তথ্য শূন্য।
- Deho.ai (২০,৫৩৬ ফ্যাসিলিটি), DhakaDocs (৪,০০০+ ডাক্তার) — দিনের ডিরেক্টরি; open-now ফিল্টার নেই, ফার্মেসি ক্যাটাগরিই নেই।
- জার্মানি (Aponet.de Notdienst), ফ্রান্স (MonPharmacien) — ডিউটি-ফার্মেসি অফিসিয়াল সিস্টেম; বাংলাদেশে চাহিদা প্রমাণিত, সরবরাহ শূন্য।

## প্রোডাক্ট
- **১২ ক্যাটাগরি**: ফার্মেসি, হাসপাতাল ইমার্জেন্সি, ২৪ঘ ডায়াগনস্টিক, ফুয়েল/CNG, এটিএম বুথ, অ্যাম্বুলেন্স, রক্তের ব্যাংক, ফায়ার সার্ভিস, থানা/পুলিশ, ভেটেরিনারি, রাতের হোটেল-রেস্টুরেন্ট, গাড়ি/বাইক মেকানিক। (ফায়ার/থানা/হাসপাতাল ইমার্জেন্সি = পূর্ণ তালিকা; বাকিগুলোতে শুধু রাতে-খোলা এন্ট্রি।)
- **মূল ফিচার**: "এখন খোলা" ফিল্টার (opening_hours পার্সিং, ডিফল্ট ON), ট্যাপ-টু-কল, প্রতি এন্ট্রিতে যাচাই-তারিখ, কমিউনিটি রিপোর্ট (৪৮ ঘণ্টায় রি-ভেরিফিকেশন), ফেসবুক/মেসেঞ্জার শেয়ার।
- **যা নয়**: রেস্টুরেন্ট রিভিউ সাইট, ডেলিভারি অ্যাপ, ইয়েলো পেজ নয়। ভবিষ্যতের জিম-বাজার-পার্কিং আলাদা সেকশনে যাবে।
- পজিশনিং: গুগল জানে "কোথায় আছে"; রাতজাগা জানে "এখন খোলা কিনা, কতক্ষণ, কে যাচাই করল"।

## ডেটা
- OSM ঢাকা লাইভ টেস্ট (১৭-১০-২০২৬): ফার্মেসি ১,৮২১ / এটিএম ৬২৩ / হাসপাতাল ৪৬৫ / ফুয়েল-CNG ২৩০ / থানা ১৩৫ / ফায়ার স্টেশন ২৬।
- **সিড উৎস (সবই ফ্রি)**: OSM + Overpass API; DGDA লাইসেন্সড ফার্মেসি তালিকা; DGHS HRIS (৯,০০০+ এন্ট্রি); মেঘনা/পদ্মা/জামুনা ফিলিং স্টেশন PDF; ব্যাংক ATM লোকেটর; রক্ত: কোয়ান্টাম/সন্ধানী/বাঁধন।
- **ভেরিফিকেশন ফ্লাইহুইল**: সিড → ফোন-যাচাই → কমিউনিটি সাবমিশন (মডারেশন কিউ) → রিপোর্ট-লুপ; ৩ মাস যাচাইহীন এন্ট্রি = "পুরনো"।
- ইঞ্জিনিয়ারিং: খোলা-র-সময় opening_hours পার্স করে নির্ণয় — শুধু "24/7" ট্যাগে আটকে থাকলে ৯৯% রাতের ফার্মেসি মিস হবে।

## টেক স্ট্যাক (সম্পূর্ণ ফ্রি)
- ফ্রন্টএন্ড: Next.js + Tailwind; হোস্টিং: Cloudflare Pages (আনলিমিটেড ব্যান্ডউইথ — ভাইরাল ট্রাফিক-স্পাইক নিরাপদ); DB+অথ: Supabase (Postgres, ৫০০MB ফ্রি); ম্যাপ: Leaflet + OSM টাইল (API কী লাগে না); PWA।
- ডিজাইন: ডার্ক-ফার্স্ট (নেভি-ব্ল্যাক + অ্যাম্বার), বাংলা-ফার্স্ট (Hind Siliguri), কল-ফার্স্ট, ক্যাটাগরি কালার-কোডিং, সব স্ক্রিনে জরুরি ৯৯৯ বাটন; ডেস্কটপ split-view, মোবাইল ট্যাব।
- ডোমেইন: raatjaga.com (উপলব্ধ, whois যাচাইকৃত) ≈ ৳১২৫/মাস।

## রোডম্যাপ
০. ডেটা সিড (সপ্তাহ ১–৩): ৩০০+ যাচাইকৃত এন্ট্রি → ১. MVP লঞ্চ (সপ্তাহ ৪–৬): পাবলিক বিটা → ২. কমিউনিটি (মাস ২–৩): লগইন, সাবমিশন কিউ, মডারেটর প্যানেল, শেয়ার-রেফার → ৩. আয় (মাস ৪+): ফিচার্ড লিস্টিং পাইলট → ৪. সম্প্রসারণ (মাস ৬+): চট্টগ্রাম-সিলেট → জেলাশহর, Play Store র‍্যাপার।

## খরচ ও আয়
- বছর-১ মোট ≈ **৳১,৮০০** (স্ট্যাক ৳০ + ডোমেইন ৳১,৫০০ + ফোন-যাচাই কলচার্জ ৳৩০০)। (প্রচ্ছদের ব্যাজে ৳১,৫০০ — ডকুমেন্টে সামান্য অসঙ্গতি।)
- আয় (মাস ৪+): ফিচার্ড লিস্টিং ৳৫০০–২,০০০/মাস, ক্যাটাগরি স্পনসরশিপ (লেবেলড), অ্যাম্বুলেন্স/ডায়াগনস্টিক লিড।
- মূলনীতি: মুক্ত ডেটা কখনো পেইংওয়ালে যাবে না; বিজ্ঞাপন সার্চ-ফলাফলের সত্যতা প্রভাবিত করবে না (স্পনসর্ড সবসময় লেবেলড)।

## সফলতার মেট্রিক
- লঞ্চে: ৩০০+ ফোন-যাচাইকৃত এন্ট্রি, ৬ ক্যাটাগরি, ঢাকার ১০+ এলাকা।
- মাস ৩: ৫০০+ দৈনিক সার্চ, কল-ক্লিক রেট ৩৫%+, রিপোর্ট ক্লোজার ৪৮ঘ-র মধ্যে ৯০%+।
- মাস ৬: ১,০০০+ দৈনিক ভিজিটর, ১,০০০+ এন্ট্রি, ২০+ কমিউনিটি কনট্রিবিউটর।
- মাস ৯: প্রথম মাসিক রেভিনিউ (ফিচার্ড লিস্টিং)।

## ঝুঁকি → প্রতিকার
- তথ্য পুরনো হয়ে যাওয়া (উচ্চ) → যাচাই-তারিখ বাধ্যতামূলক, রিপোর্ট-লুপ, ৩-মাস রি-ভেরিফিকেশন।
- ভুয়া/স্প্যাম (মাঝারি) → মডারেশন কিউ + প্রকাশের আগে ফোন ভেরিফিকেশন।
- গুগল একই ডেটা যোগ করলে (কম) → কমিউনিটি + বাংলা + মাল্টি-ক্যাটাগরি ডিফারেন্সিয়েশন।
- ফ্রি-টিয়ার লিমিট (কম) → $৩–৫/মাস VPS (তখন রেভিনিউও চালু)।
- একক-ব্যক্তি নির্ভরতা (মাঝারি) → মডারেটর রিক্রুট + ডকুমেন্টেড SOP।

## সিদ্ধান্ত: always-usable সম্প্রসারণ (২০২৬-১০-১৭)
ব্যবহারকারীর সিদ্ধান্ত: **শুধু রাতভিত্তিক নয় — প্ল্যাটফর্ম সবসময় ব্যবহারযোগ্য হতে হবে।** মূল সূত্র: প্রজেক্টের আসল সম্পদ "রাতের ডেটা" নয়, ভেরিফিকেশন ফ্লাইহুইল — সেটা যেকোনো সময়-সংবেদনশীল প্রশ্নে চলে: "এখন কী খোলা/চালু/নেই?"

- **টিয়ার ১ (নতুন ডেটা ছাড়াই, লঞ্চেই)**: "এখন খোলা" ফিল্টার ২৪ঘ — দুপুরের বিরতি, সাপ্তাহিক বন্ধ, সরকারি ছুটিও opening_hours পার্সিং-ই ধরে; কার্ডে "সাপ্তাহিক বন্ধ/বিরতি" ব্যাজ; PWA অফলাইন-ক্যাশ (লোডশেডিং/নেটহীন অবস্থায় শেষ যাচাইকৃত তালিকা)।
- **টিয়ার ২ (মৌসুমি/ইমার্জেন্সি মোড — ভাইরাল ইঞ্জিন)**: ছুটি/ঈদ/হরতাল মোড ("আজ শুধু যা খোলা"); রমজান মোড (সেহরি-ইফতারে উল্টে যাওয়া সময়সূচি); দুর্যোগ মোড (বন্যা/ডেঙ্গুতে বেড-অক্সিজেন-শেল্টার — ভাইরাল হওয়া লিস্টগুলোর স্থায়ী ঘর, প্রস্তাবনা নিজেই এ ফাঁক উল্লেখ করেছে)।
- **টিয়ার ৩ (always-on ক্যাটাগরি — দিনের ব্যবহার)**: কুরিয়ার হাব (Pathao/RedX/Steadfast ব্রাঞ্চ), ডাক্তারের চেম্বার শিডিউল ("আজ বসবেন কি না"), সরকারি সেবাকেন্দ্র (UDC, পাসপোর্ট অফিস, ব্যাংক ব্রাঞ্চ), হাটবার (জেলা-সম্প্রসারণের কিলার ফিচার), মসজিদ/জামাতের সময়, মার্কেট-মল, লঞ্চ ঘাট/ট্রেন কাউন্টার, জিম-সুইমিং পুল। **২০২৬-১০-১৭ সাইটে যোগ হয়েছে**: কমদামি বাজার, পাইকারি বাজার, পাবলিক টয়লেট (মোট ক্যাটাগরি ১৫) — দাম-তুলনা পরে আলাদা সেকশনে (বিজ্ঞাপন-সত্যতা নীতি মেনে)।
- **টিয়ার ৪ (স্ট্যাটাস লেয়ার — পরে; সবচেয়ে দামি, সবচেয়ে কঠিন)**: ওষুধ স্টক ("ইনসুলিন আছে কি?"), হাসপাতালের বেড/অক্সিজেন; হাসপাতাল/চেইন নিজেরা আপডেট দিতে পেমেন্ট করতে পারে — ফিচার্ড লিস্টিংয়ের রেভিনিউ-সংযোগ।
- **সতর্কতা**: একসাথে সব নয় — লঞ্চে রাত + "এখন খোলা" (টিয়ার ১) থাকবে, বাকি স্তর ধাপে ধাপে; প্রতিটি নতুন ক্যাটাগরিতে নীতি এক: রিভিউ/দাম নয়, শুধু "এখন চালু কি না"।
- **ব্র্যান্ড**: নাম "রাতজাগা" থাকবে, প্রমিজ বসবে "এখন"-এ — ট্যাগলাইন সম্ভাবনা: "যা দরকার, এখন যা খোলা।" রাত = ফ্ল্যাগশিপ ইউজ-কেস, সীমানা নয়।

## অ্যাডমিন/মডারেটর প্যানেল
আলাদা অ্যাপ নয় — একই Next.js অ্যাপের `/admin` রুট, Supabase বিল্ট-ইন অথ + role-based access (RLS), খরচ ৳০। ভূমিকা: super-admin, moderator। MVP-তে হালকা (শুধু সাবমিশন approve/reject), ফেজ ২-এ পূর্ণ। কাজগুলো:
- সাবমিশন কিউ: নতুন এন্ট্রি অনুমোদন/বাতিল; প্রকাশের আগে ফোন ভেরিফিকেশন বাধ্যতামূলক।
- রিপোর্ট হ্যান্ডলিং: "বন্ধ/ভুল" রিপোর্টে ৪৮ ঘণ্টার ক্লক; কে হ্যান্ডেল করল তার অডিট-লগ।
- যাচাই-ট্র্যাকিং: শেষ ফোন-যাচাইয়ের তারিখ, ৩-মাস সাইকেল, stale এন্ট্রি ফ্ল্যাগ + রি-ভেরিফিকেশন তালিকা।
- কনট্রিবিউটর ম্যানেজমেন্ট: রেপুটেশন, স্প্যামার ব্যান।
- মেট্রিক ড্যাশবোর্ড: সার্চ, কল-ক্লিক, রিপোর্ট ক্লোজার — সফলতার মেট্রিকের সাথে মিলিয়ে।
